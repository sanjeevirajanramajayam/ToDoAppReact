# ✅ To-Do App (React.js)

This is a simple **To-Do App** built using **React.js**. The app allows users to:
- Add new tasks
- Mark tasks as complete or incomplete
- Delete tasks

## 🚀 Features
- **Add Tasks**: Users can add tasks with a title.
- **Toggle Task Completion**: Mark tasks as completed or pending.
- **Delete Tasks**: Remove tasks from the list.

## 📁 Tech Stack
- **React.js** (for building the user interface)
- **CSS** (for styling)

## 💡 Purpose

This project aims to provide a simple yet effective interface for managing tasks. It also serves as a great project for learning **React's state management**, **component composition**, and **event handling**.
